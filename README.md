# 🎯 Shadow Matching Game

A simple and interactive **Shadow Matching Game** built using **HTML, CSS, and JavaScript**. The player needs to identify and select the correct shadow that matches the displayed object.

## 🎮 Game Features

* 🖼️ Displays different objects randomly.
* 🌑 Provides multiple shadow options.
* ✅ Checks whether the selected shadow is correct.
* ❌ Shows a message for incorrect answers.
* 🏆 Keeps track of the player's score.
* 🔄 Generates a new question using the **Next** button.
* 📱 Simple and responsive user interface.

## 🛠️ Technologies Used

* **HTML5** – Creates the game structure.
* **CSS3** – Provides styling, layout, and animations.
* **JavaScript** – Handles game logic, random questions, answer checking, and score calculation.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start matching the objects with their shadows.

## 🕹️ How to Play

1. An object is displayed on the screen.
2. Three shadow options are provided.
3. Click the shadow that matches the object.
4. A **Correct** or **Wrong** message will be displayed.
5. Click **Next** to continue.
6. Your score increases for every correct answer.
